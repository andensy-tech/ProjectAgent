# HEARTBEAT — 定期维护任务清单

## 记忆系统维护

- **蒸馏（Distillation）**：每 10 轮对话自动触发，将近期对话日志提炼为长期记忆
  - 词频统计 → 更新 learned_preferences
  - LLM 语义分析 → 提取用户偏好、决策、经验教训
- **清理（Cleanup）**：每次蒸馏时同步执行
  - 删除 30 天前的日志
  - 删除低使用率（<3次）+ 低成功率（<30%）+ 超过 90 天的学习记录
- **搜索索引同步**：每次搜索前自动同步 FTS5 索引
- **向量嵌入计算**：新保存的记忆自动生成嵌入
  - 全量回填：POST /api/memory/embeddings/backfill

## 会话结束维护

- **内存冲洗**：会话压缩、最大工具轮次、服务关闭时自动执行
  - 保存工作记忆中的实体 → learning_records
  - 保存上下文变量 → learned_preferences
  - 检测决策关键词 → 保存为决策记录

## 启动时检查

- 检查是否存在未蒸馏的日志 → 自动触发蒸馏
- 重建 FTS5 搜索索引（自动同步）
